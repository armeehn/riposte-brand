\textbf{Document colour mode:}

\begin{ripbullets}
\item Screen → \textbf{RGB}, sRGB IEC61966-2.1
\item Print → \textbf{CMYK}, and read \ripdocref{\ripmono{.\allowbreak{}.\allowbreak{}/\allowbreak{}docs/\allowbreak{}08-\allowbreak{}print.\allowbreak{}md}}{RL-BRAND-001-PRINT} first. \end{ripbullets}

\ripsection{\ripmdhead{3 · Objects}}

\begin{ripbullets}
\item \textbf{Corner radius 0.} Set Live Corners to 0 and leave them there.
\item \textbf{Strokes:} 2pt structural, 0.5pt dashed dividers, 6pt accent top bars, 8pt accent left bars. Align stroke to \textbf{outside} so the border doesn't eat the fill.
\item \textbf{Effects: none.} No Drop Shadow, no Inner Glow, no Feather, no Gaussian Blur.
\item \textbf{Hard offsets instead:} duplicate the object, fill with the accent, send backward, offset \ripmono{+4pt / +4pt}. Or use \riphi{Effect → Distort \& Transform → Transform} with Move \ripmono{4pt/4pt} and 1 copy — non-destructive and editable.
\end{ripbullets}


\ripsection{\ripmdhead{4 · The three patterns}}


\ripsubsection{\ripmdhead{Tri-band}}

Gradient, linear, \textbf{105°}, with paired stops so the boundaries are hard: pink at 0\% and 36\%, marigold at 36\% and 64\%, teal at 64\% and 100\%.


\ripsubsection{\ripmdhead{Checker}}

22pt ink square → 2×2 alternating block → \textbf{Object → Pattern → Make}. Band height 26pt with 2pt ink rules top and bottom.


\ripsubsection{\ripmdhead{Harlequin}}

34pt squares rotated 45°, alternating pink/teal, made into a pattern. Band height 38pt.

Save all three into a \textbf{Riposte} library (\ripmono{.ai} CC Library / Affinity Assets).


\ripsection{\ripmdhead{5 · InDesign documents}}

\begin{ripmdtable}{X[0.55,l]X[1.60,l]}
\ripmdth{SETTING} & \ripmdth{VALUE} \\
Margins & 15mm minimum, 18mm preferred \\
Bleed & 3mm, bands extended into it \\
Baseline grid & Off. The system uses a stack order, not a baseline grid \\
Columns & Gutter 8mm (the print translation of 34px) \\
\end{ripmdtable}

Master pages carry the corner marks (\ripmono{DOC NO.}, \ripmono{REV.}), the page number, and the colophon footer. Build paragraph styles from the table in §2 and never apply local overrides.


\ripsection{\ripmdhead{6 · Photoshop}}

Photoshop is for photo treatment, and the brand barely uses photography. If you must:

\begin{ripbullets}
\item Flat, high contrast, on bone. Never soft, never rounded, never vignetted.
\item No layer styles — every one of them is a blur, a bevel or a glow.
\item Export at 2× for screen. PNG for flat artwork, not JPEG.
\end{ripbullets}
