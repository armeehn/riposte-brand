\ripsection{\ripmdhead{1 · Font}}

Google Fonts includes \textbf{JetBrains Mono}, but it isn't in the Docs/Slides font menu by default. Add it:

\textbf{Font dropdown → More fonts → search "JetBrains Mono" → add.}

If it doesn't appear on your account, use \textbf{Roboto Mono} — natively available and the safest cross-platform fallback. Note the substitution when you share the file.


\ripsection{\ripmdhead{2 · Custom colours}}

Google's colour picker has no palette import. Enter hex values once via \textbf{Custom → hex field} and they'll stay in your recent-colours row for that document. Copy the finished document rather than re-entering them.

\ripcodeopen

\begin{ripcodeblock}
INK          #1D1A17      BONE          #F6F1E7
INK RAISED   #241F1B      BONE DIM      #EAE4D6
INK LINE     #5C554C      WHITE         #FFFFFF

PINK         #F0477D      PINK DEEP     #D81150

\ripcodesizereset\ripcodeclose

\textbf{Text on accent fills:} bone on pink, \textbf{ink on marigold}, bone on teal — and only at large uppercase sizes. Body copy on a coloured fill needs a \ripmono{DEEP} colour underneath it.

Google Slides has \textbf{no letter-spacing control}. Two options for the tracked chrome:

\begin{ripnumbers}
\item Type spaces between characters: \ripmono{S E C . 0 3}. Ugly to edit, right on the eye.
\item Accept untracked labels. Better than faking it with a different font.
\end{ripnumbers}


\ripsubsection{\ripmdhead{Slide furniture}}

\begin{ripbullets}
\item \textbf{Corner marks:} a 12pt text box top-left \ripmono{DOC NO.\allowbreak{} RL-\allowbreak{}000-\allowbreak{}A}, top-right \ripmono{REV. A}, bottom-right the slide number. 75\% opacity.
\item \textbf{Checker band:} insert \ripmono{assets/\allowbreak{}patterns/\allowbreak{}checker-\allowbreak{}band.\allowbreak{}png} (or build a 22px square, group a 2×2, duplicate across).
\item \textbf{Section dividers:} full-bleed ink rectangle, bone title. This is the ink field.
\item \textbf{Corner rounding: 0.} Shape options → shape → the square, never the rounded rectangle.
\item \textbf{Shadows off.} Format options → uncheck Drop shadow, on every element.
\end{ripbullets}

\ripsubsection{\ripmdhead{Furniture}}

\begin{ripbullets}
\item \textbf{Header:} \ripmono{DOC NO.\allowbreak{} RL-\allowbreak{}000-\allowbreak{}A} left, \ripmono{REV. A} right, 8pt, 75\% grey

\item \textbf{Tables:} header row \ripmono{\#EAE4D6}, header text uppercase bold, 1.5pt bottom border on the header, 0.5pt dashed between rows.
\end{ripbullets}


\ripsection{\ripmdhead{5 · Sheets}}

\begin{ripbullets}
\item Header row: \ripmono{\#1D1A17} background, \ripmono{\#F6F1E7} bold uppercase text
\item Banding: off. Use a 0.5pt bottom border per row instead — the brand separates with rules, not fills
\item Conditional formatting: pass \ripmono{\#12B795}, warn \ripmono{\#FE9A0D}, fail \ripmono{\#F0477D} — always with a \ripmono{✓ ! ✕} glyph in an adjacent column, never colour alone
\item Charts: flat accent fills in rotation, no gradients, no 3-D, no drop shadows, gridlines off
\end{ripbullets}


\ripsection{\ripmdhead{6 · Known limits}}

\begin{ripmdtable}{X[0.58,l]X[1.42,l]}

Rounded shapes by default & Always pick the square variant, rounding 0 \\
